# AWS Cloud Infrastructure Project

## Project Overview
Designed and implemented an AWS cloud infrastructure using EC2, Application Load Balancer (ALB), Target Groups, EFS, Security Groups, and Linux.

## AWS Services Used
- Amazon EC2
- Application Load Balancer
- Target Groups
- Amazon EFS
- Security Groups
- Linux

## Project Implementation
- Configured EC2 instances.
- Set up an Application Load Balancer and Target Group.
- Configured Amazon EFS for shared storage.
- Configured Security Groups for network access.
- Used Linux for server configuration and management.

## Key Learning
Gained practical experience with AWS infrastructure, load balancing, shared storage, and Linux server administration.
